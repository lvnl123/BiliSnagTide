# BiliSnagTide v4.6.2 — 登录保存、线路保护与精简便携包

本版本针对 v4.6.1 的实际使用问题修复，保留直播源、弹幕、播放器与主题功能。

## 修复与改进

- **持久登录：** QR 扫码完成后，使用 Windows DPAPI 以当前 Windows 用户身份加密保存必要的 Bilibili Cookie。重新打开软件时自动恢复并调用官方账号接口验证。账号头像和昵称显示在顶部，点击打开「设置与代理」账号管理，支持更换账号和退出登录。登录失效需重新扫码；复制便携文件夹到另一台机器也需要重新登录。
- **线路不会因复制失败而丢失：** 复制前刷新失败、或 Windows 剪贴板被占用时，不再破坏现有线路列表。单画质刷新会合并新的候选线路，不会整批清除其他 CDN 候选。新增「清除筛选 · 全部线路」，以及显示/总候选线路数量。
- **重新扫描 2K 请求：** 画质扫描的兼容 QN 请求集合补全 15000，是否能返回 2K 仍以服务器为准。
- **精简绿色版：** 绿色 ZIP 现在主要只有一个含 .NET 运行时的 `BiliSnagTide.exe`，另外保留一个极小的 `portable.flag` 以便老版本内置更新器识别；首次启动生成 `Data/` 保存设置。系统运行时可能自行解包原生组件到系统临时目录。
- **更新中心：** 更新为 v4.6.2 版本识别，绿色 ZIP 升级迁移时一并迁移本机加密会话文件。

## 下载

- `BiliSnagTide-v4.6.2-Windows-x64-Portable.zip` — 绿色便携 ZIP，完整解压后运行 `BiliSnagTide.exe`；请保留 ZIP 内的 `portable.flag`。
- `BiliSnagTide-v4.6.2-Windows-x64-Setup.exe` — 安装版，可正常卸载。
- `SHA256SUMS.txt` — 下载包 SHA-256 校验清单。

## 注意

- 项目为第三方非官方软件。不保证所有直播间都有多个可用 CDN、全部清晰度或固定格式。
- 本地保存的会话采用 Windows 当前用户 DPAPI 加密，不是跨设备同步登录；如需迁移到另一台电脑，请重新扫码。
- 登录凭据不会放入 `settings.json`、M3U 或诊断日志，`Data/account-session.dpapi` 请勿公开分享。
- 本版本未作 Windows 用户交互式端到端测试，实际登录、头像和跨版本更新仍应在本机验证。
